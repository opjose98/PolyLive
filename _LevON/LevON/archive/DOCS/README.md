# Documentación General (DOCS)

Esta carpeta está reservada para documentación extensa generada manualmente, diagramas arquitectónicos exportados en imágenes o especificaciones detalladas que excedan el marco de un simple `CONTEXT.md` o `ARCHITECTURE.md`.

## Normas
- Evitar redundancia con los archivos raíz.
- Optimizar para Markdown (evitar PDFs si es posible para facilitar que agentes IA puedan leer la documentación en plano).
- Cualquier diagrama de flujo debe, preferiblemente, incluir su código fuente (Mermaid, PlantUML) embebido en un `.md` para permitir su modificación futura sin requerir el software original.
